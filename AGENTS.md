# Asasera media rules

For image or sound generation, editing, regeneration, prompt construction, or selection of application media, read `src/shared/media-policy.ts` first. Include its complete `MEDIA_GENERATION_POLICY` text in every generation prompt, including calls to external tools. Use `mediaGenerationPrompt` when constructing prompts in code. This file is generated from the backend's `packages/shared/src/media-policy.ts`; edit that source and synchronize the shared contract.

These are firm owner requirements: dry, non-tonal digital/mechanical sound effects only; no melodic or vocalized audio; no generated depictions of women or girls, including cartoons. Prefer people-free educational objects and environments. Preserve these constraints when changing providers or accepting teacher-supplied briefs. Review generated output before application use; a compliant prompt alone does not prove compliance. Historical prompt metadata is provenance, not an approved reusable prompt.
